# Objetivo general

**Estado:** especificación documental; no acredita implementación ni resultados.

**Fuente:** document.md y powerpoint.md · objetivos; diapositiva 4. Véase [[tesis/referencias#Fuentes, cobertura y decisiones pendientes|Fuentes y pendientes]].

Desarrollar un sistema inteligente de recomendación vocacional mediante un modelo de aprendizaje automático supervisado para apoyar la elección vocacional.

El universo operativo se acota a las carreras del IPN dentro del área seleccionada y a estudiantes de educación media superior de la Ciudad de México.
