# Metodología de trabajo

**Estado:** especificación documental; no acredita implementación ni resultados.

**Fuente:** document.md · metodología y articulación. Véase [[tesis/referencias#Fuentes, cobertura y decisiones pendientes|Fuentes y pendientes]].

Enfoque híbrido: cascada para ordenar etapas y prácticas de Scrum para gestionar iteraciones.

| Etapa | Producto esperado |
| --- | --- |
| Requerimientos | Catálogo de funciones, restricciones, interfaz e implementación |
| Diseño | Arquitectura, datos, contratos, interfaces y procedimiento de análisis |
| Implementación | Servicios, datos, modelos, integración y despliegue |
| Pruebas y resultados | Evidencias de cumplimiento, evaluación y correcciones |

Cada iteración revisará avance técnico e integración. No se especifican duración de sprints ni responsables.
