# Índice - Tesis y Documentos Académicos

La documentación se organiza por encabezados temáticos de `document.md` y `powerpoint.md`. Los puntos de cada apartado permanecen dentro del mismo archivo y los encabezados compartidos se consolidan.

Los requisitos se organizan en cuatro archivos: funcionales, no funcionales, implementación e interfaz. Implementación, pruebas y conclusiones incluyen la estructura para las etapas posteriores solicitadas; no acreditan resultados ni implementación verificada.
